## 📖 Présentation

Ce document constitue une réécriture et une consolidation de plusieurs supports pédagogiques autour du développement Android. Il vise à fournir une **introduction progressive et structurée** à la programmation d'applications Android, en particulier pour les tablettes.

Il intègre plusieurs évolutions majeures :

* Adoption de **Android Studio** comme environnement de développement principal
* Utilisation du système de build **Gradle**
* Introduction de **RxJava** pour la gestion de l’asynchronisme
* Structuration avancée des applications Android (fragments, cycle de vie, architecture client/serveur)

Ce document se distingue notamment par la présentation d’un **squelette générique d’application Android client/serveur**, réutilisable dans de nombreux projets.



---

## 🎯 Objectifs pédagogiques

* Comprendre les bases du développement Android
* Maîtriser la navigation entre vues et fragments
* Gérer le cycle de vie des composants Android
* Implémenter des architectures client/serveur
* Manipuler des données via des interfaces utilisateur
* Introduire la programmation asynchrone avec RxJava
